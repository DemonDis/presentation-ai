Альтернатива Gamma.app с открытым исходным кодом — генератор презентаций на основе ИИ, который создаёт красивые настраиваемые слайды за считанные минуты. Этот инструмент является частью более широкой платформы ALLWEONE AI.

## 🌟 Возможности

### Основной функционал

- **Генерация контента на основе ИИ**: Создание полных презентаций на любую тему с помощью ИИ
- **Рабочий процесс на основе структуры**: Сначала создайте структуру, просмотрите её, затем превратите в слайды
- **Настраиваемые слайды**: Выберите текстовую модель, количество слайдов, язык и возможность включения веб-поиска
- **Пустые презентации**: Начните с нуля, если не хотите использовать контент, сгенерированный ИИ
- **Редактируемые структуры**: Просмотрите и измените сгенерированные ИИ структуры перед финализацией
- **Генерация в реальном времени**: Наблюдайте, как ваша презентация создаётся в прямом эфире
- **Автосохранение**: Всё автоматически сохраняется во время работы

### Дизайн и кастомизация

- **Множество тем**: 38 встроенных тем доступны из коробки
- **Создание пользовательских тем**: Создавайте, сохраняйте и используйте свои собственные темы
- **Импорт тем из PPTX**: Импортируйте вдохновение для тем напрямую из файлов PowerPoint
- **Полная редактируемость**: Изменяйте текст, шрифты и элементы дизайна по мере необходимости
- **Генерация изображений**: Выберите различные модели ИИ для генерации изображений для ваших слайдов
- **Стили, ориентированные на аудиторию**: Выберите между профессиональным и неформальным стилями презентации

### Инструменты для презентаций

- **Режим презентации**: Проводите презентации прямо из приложения
- **Публичный доступ**: Создайте общую ссылку для презентаций
- **Запись презентаций**: Записывайте презентации с управлением микрофоном и веб-камерой
- **Экспорт в PowerPoint**: Экспортируйте презентации в формат `.pptx`
- **Диаграммы, инфографика и медиа-вставки**: Добавляйте более богатый визуальный контент помимо текстовых слайдов
- **Расширенное редактирование текста**: Powered by Plate Editor для комплексной работы с текстом и изображениями
- **Перетаскивание**: Интуитивное изменение порядка слайдов и манипуляция элементами

## 🚀 Начало работы

### Требования

Перед началом убедитесь, что у вас установлено следующее:

- Node.js 18.x или выше
- npm, yarn или pnpm менеджер пакетов
- База данных PostgreSQL
- Google Client ID и Secret (для аутентификации)
- Ключи провайдеров в зависимости от функций, которые вы хотите использовать:
  - OpenAI API key (для облачной генерации текста)
  - Together AI API key (для генерации изображений)
  - FAL API key (для дополнительных потоков генерации изображений)
  - Tavily API key (для веб-поиска)
  - Unsplash access key (для стоковых изображений)

### Установка

1. **Клонируйте репозиторий**

   ```bash
   git clone git@github.com:allweonedev/presentation-ai.git
   cd presentation-ai
   ```

2. **Установите зависимости**

   ```bash
   pnpm install
   ```

3. **Настройте переменные окружения**

   Создайте файл `.env` в корневой директории со следующими переменными:

   ```env
   # База данных
   DATABASE_URL="postgresql://username:password@localhost:5432/presentation_ai"

   # Аутентификация
   NEXTAUTH_SECRET=""
   NEXTAUTH_URL="http://localhost:3000"

   # Google OAuth Provider
   GOOGLE_CLIENT_ID=""
   GOOGLE_CLIENT_SECRET=""

   # AI провайдеры
   OPENAI_API_KEY=""
   TOGETHER_AI_API_KEY=""
   FAL_API_KEY=""

   # Сервис загрузки файлов
   UPLOADTHING_TOKEN=""

   # Дополнительные провайдеры поиска и медиа
   UNSPLASH_ACCESS_KEY=""
   TAVILY_API_KEY=""
   ```

   > 💡 **Совет**: Скопируйте `.env.example` в `.env` и заполните вашими реальными значениями. Если вы планируете использовать локальные текстовые модели через Ollama или LM Studio, вы можете запускать генерацию текста без `OPENAI_API_KEY`.

### Настройка базы данных

1. **Инициализируйте базу данных**

   ```bash
   pnpm db:push
   ```

2. **Запустите сервер разработки**

   ```bash
   pnpm dev
   ```

3. **Откройте приложение**

   Перейдите по адресу [http://localhost:3000](http://localhost:3000) в вашем браузере.

### Доступные скрипты

```bash
pnpm dev       # Запуск сервера разработки Next.js
pnpm build     # Сборка приложения
pnpm start     # Запуск продакшн сервера
pnpm db:push   # Отправка Prisma схемы в базу данных
pnpm db:studio # Открытие Prisma Studio
pnpm type      # Запуск проверки типов TypeScript
pnpm check     # Запуск проверок Biome
pnpm lint      # Запуск линтинга Biome
```

## 💻 Использование

### Создание презентации

Выполните следующие шаги, чтобы создать вашу первую презентацию, сгенерированную ИИ:

1. Войдите в приложение
2. Перейдите в панель управления презентациями
3. Введите тему вашей презентации
4. Выберите текстовую модель (OpenAI, Ollama или LM Studio)
5. Выберите количество слайдов (рекомендуется: 5-10)
6. Выберите предпочитаемый язык
7. Включите веб-поиск, если хотите включить внешний контекст
8. Нажмите **"Сгенерировать структуру"**
9. Просмотрите и отредактируйте сгенерированную ИИ структуру
10. Выберите тему для вашей презентации
11. Выберите источник изображений (ai / стоковые)
12. Выберите стиль презентации (Professional/Casual)
13. Нажмите **"Сгенерировать презентацию"**
14. Дождитесь, пока ИИ создаст ваши слайды в реальном времени
15. Просмотрите, отредактируйте и доработайте презентацию по мере необходимости
16. Проведите презентацию прямо из приложения или экспортируйте её

### Пользовательские темы

Создавайте персонализированные темы, соответствующие вашему бренду или стилю:

1. Нажмите **"Создать новую тему"**
2. Начните с нуля или создайте на основе существующей темы
3. Настройте цвета, шрифты и макет
4. Сохраните вашу тему для будущего использования

## 🧠 Руководство по локальным моделям

ALLWEONE Presentation AI теперь поддерживает как Ollama, так и LM Studio в качестве локальных провайдеров моделей.

### LM Studio

1. Установите [LM Studio](https://lmstudio.ai).
2. В приложении LM Studio включите Server и разрешите CORS.
3. Загрузите любую модель, которую хотите использовать, внутри LM Studio.

### Ollama

1. Установите [Ollama](https://ollama.com).
2. Загрузите любую модель, которую хотите использовать (например: `ollama pull llama3.1`).

### Использование локальных моделей в приложении

1. Откройте приложение и откройте селектор текстовых моделей.
2. Выберите модель, которую хотите использовать.
3. Для LM Studio сначала загрузите модель в LM Studio.
4. Для Ollama установленные модели появляются автоматически, и некоторые рекомендуемые модели можно загрузить при первом использовании.
5. Наслаждайтесь генерацией.

Заметки:

- OpenAI остаётся доступной в качестве облачной текстовой модели по умолчанию.
- Модели автоматически появятся в селекторе моделей, когда запущен сервер LM Studio или демон Ollama.
- Убедитесь, что в LM Studio включён CORS, чтобы браузер мог подключиться.
